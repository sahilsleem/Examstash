# Contributing to ExamStash 📚

Thank you for your interest in contributing to ExamStash! Our goal is to make educational resources accessible and free for students across India.

---

## 🌟 Ways to Contribute

### 1. 📄 Submitting Question Papers & Syllabi
The most impactful way to help is sharing past exam papers from your school, college, or university:
- Take clear photos or scan your question papers to PDF.
- Share them via Telegram: **[@sahilsleem](https://t.me/sahilsleem)**
- Or email them to: **`examstash1@gmail.com`**

### 2. 💻 Adding Papers via Pull Request
If you are comfortable with Git and Python:
1. Fork this repository.
2. Run `python add_paper.py` to add your paper and compile the new page.
3. Test locally using `python -m http.server 8000`.
4. Validate site health with `python validate_site.py`.
5. Submit a Pull Request to `main`.

### 3. 🐛 Reporting Issues & Broken Links
If you find a broken link, missing page, or styling issue:
- Open a GitHub Issue with the page URL and details.

---

Thank you for helping students succeed! 🎓
